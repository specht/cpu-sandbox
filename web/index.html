Instruction reference

Three compatible architectures: MiniCPU 8 has 256 bytes of shared RAM. MiniCPU 8S adds a downward-growing stack, PUSH/POP and CALL/RET. MiniCPU 8X has 4096 bytes of shared RAM, a 16-bit program counter, 16-bit index registers X/Y, and automatically selected short/long jumps and calls. All A–D registers are still 8-bit; all models share the same grouped opcode table. Select an architecture above to assemble for it. Programs start at 0x0000.

8X onlyLDX 0x0800 · STA [X], A · LDA A, [X] · INCX · DECX · LDY 0x0900 · LDA A, [Y] · STA [Y], A · INCY · DECY. Jumps and CALL automatically use short PC-relative or long absolute encoding, depending on distance; the mnemonics stay the same.
Directives.org 0x60 · .db 1, 2, "Hi" · SIZE .equ 16 · .display 0x80, 32, 16, mono, 1bit_monitor_glow

Numbers can be decimal, 0x hexadecimal, 0b binary, or expressions with +, -, parentheses and named constants. Comments start with ;. The educational opcode map groups control, data movement, arithmetic, logic, comparisons, stack operations, and branches into hexadecimal families. The stack shares ordinary RAM with programs and pixels.

Display controller: .display start, width, height, mode [, palette] suggests defaults; the panel lets you override them live without changing memory. Modes: mono, indexed2, indexed4, indexed8, gray8, rgb332, rgb24. Rows are packed consecutively with byte alignment. Packed indices use the most significant bits first. Indexed palettes must have exactly 2, 4, 16, or 256 colors for the selected bit depth. Metadata creates no instructions and consumes no RAM.

Note: CPU execution is capped to prevent infinite loops from freezing the browser. Unbounded example programs are intentionally left running until you pause or hit the limit.
